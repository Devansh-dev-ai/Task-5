# Task 7 – Responsive Laundry Service Website

## Project Description
This project is a responsive laundry service landing page developed using HTML and CSS. The website promotes laundry services through an attractive hero section containing headings, a short description, a call-to-action button, and an illustrative image.

The main objective of this project is to practice CSS Flexbox, media queries, and responsive web design to ensure the website adapts to different screen sizes.

## Features

- **Navigation Bar:** Contains a logo, navigation links (Home, Services, About Us, Contact Us), and a username button.
- **Hero Section:** Displays promotional headings, service descriptions, and a "Book a Service Today!" button.
- **Illustration:** Includes a laundry machine image to make the landing page visually appealing.
- **Responsive Navbar:** Navigation links are hidden on mobile screens while the logo and username button remain visible.
- **Responsive Layout:** The text and image are arranged horizontally on desktop and vertically on smaller screens.
- **Responsive Typography:** Font sizes and image dimensions are adjusted according to screen size.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- Viewport Units (vh and vw)

## Responsive Design

The website uses CSS media queries to adapt its layout to different screen sizes.

- **Desktop View:** Displays the navigation links and a horizontal hero section with text on the left and an image on the right.
- **Tablet View:** Reduces text sizes, image dimensions, and navbar element sizes to fit the available screen space.
- **Mobile View:** Hides navigation links, displays the logo and username button, and arranges the hero content vertically using `flex-direction: column`.
